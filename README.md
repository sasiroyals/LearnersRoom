# Learners Room

Learn Python and Java through animated, step-by-step simulations.

- Lessons: each lesson runs real code one line at a time and shows names, objects, frames and classes as they change, with predictions, a recap and a final check.
- Practice: an in-browser Python editor with a step debugger (Back / Step / Step over / Step out), powered by Skulpt.
- Curriculum: beginner to professional, with full OOP coverage, following Python Crash Course, Learning Python and Fluent Python (Python) and Head First Java, Core Java and Effective Java (Java).

The whole site is a single static page, `index.html`, hosted on GitHub Pages.
